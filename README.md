

Customer Behavior Analysis

Overview

An end-to-end Customer Behavior Analysis project that combines Python, SQL, Power BI, and Machine Learning to analyze customer purchasing behavior, generate business insights, predict subscription status, and segment customers based on shopping patterns.

⸻

Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* MySQL
* Power BI
* Matplotlib
* Seaborn
* Jupyter Notebook

⸻

Project Workflow

* Data Cleaning & Preprocessing using Python
* Exploratory Data Analysis (EDA)
* SQL Business Analysis
* Interactive Power BI Dashboard
* Logistic Regression for Subscription Prediction
* K-Means Clustering for Customer Segmentation

⸻

SQL Business Analysis

Performed business-focused SQL analysis, including:

* Revenue analysis by category
* Subscription behavior analysis
* Discount effectiveness
* Customer segmentation
* Shipping analysis
* Product performance
* Repeat customer analysis
* Age and gender-based insights

⸻

Machine Learning

Logistic Regression (Classification)

Predicted customer subscription status using purchasing behavior and demographic features.

Model Evaluation

* Accuracy: 73.4%
* Confusion Matrix
* Classification Report
* Feature Importance Analysis

K-Means Clustering

Segmented customers into three groups based on purchasing behavior:

* High-Spending Occasional Customers
* Loyal Repeat Customers
* Young Engaged Customers
