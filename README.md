
Customer Behavior Analysis Project

Project Overview

This is an end-to-end data analytics project focused on understanding customer purchasing behavior and extracting business insights from retail transaction data.

The project combines:

* Python for data cleaning and preprocessing
* SQL for business analysis and querying
* Power BI for dashboarding and visualization

The main objective of this project was to simulate a real-world data analyst workflow by transforming raw customer data into meaningful business insights and interactive visual reports.

The project explores customer spending patterns, subscription behavior, shipping preferences, review ratings, product performance, customer segmentation, and revenue trends.

This project demonstrates practical analytical thinking, business problem solving, SQL querying, and storytelling using data visualization.

Project Workflow

1. Data Cleaning & Preprocessing (Python)

Performed using Pandas in Jupyter Notebook.

Tasks completed:

* Handling missing values
* Renaming columns
* Data formatting
* Data preprocessing
* Data export to CSV

⸻

2. SQL Business Analysis

Business-oriented SQL queries were written to solve analytical problems.

Business Problems Solved

1. Which category generates the highest revenue?
2. Are discounts increasing the purchase value?
3. Total revenue generated by male and female customers.
4. Which customers used discounts but still spent more than the average purchase amount?
5. Top and bottom 5 products with the highest average review rating.
6. Average purchase comparison between Standard and Express shipping.
7. Do subscribed customers spend more?
8. Top 5 products with highest discount usage percentage.
9. Customer segmentation into new, returning, and loyal customers.
10. Are repeat buyers spending more?
11. Revenue contribution of different age groups.

Power BI Dashboard

An interactive dashboard was created in Power BI to visualize business insights.

Dashboard Features

* KPI Cards
    * Total Revenue
    * Average Purchase
    * Average Rating
    * Total Customers
* Revenue by Category
* Average Spend by Subscription Status
* Average Purchase by Shipping Type
* Gender-based Filtering (Slicer)
* Business Insights Section

⸻

Key Insights

* Electronics category generated the highest revenue.
* Subscribers spent more on average compared to non-subscribers.
* Express shipping customers showed higher purchase behavior.
* Repeat buyers contributed significantly to total revenue.
